# PetShop

Sistema de gestão de ponta a ponta para pet shop: tutores e pets, agenda com autoagendamento, pagamento por PIX, recibos e lembretes pelo WhatsApp, checklist de atendimento, PDV, estoque, recorrência e relatórios.

> Projeto em fase de definição. Comece pelo [PRD](docs/PRD.md).

## Stack prevista

- **Web:** Next.js + TypeScript na Vercel
- **Banco:** PostgreSQL na VPS (Coolify)
- **WhatsApp:** Evolution API na VPS (Coolify)
- **Pagamentos:** PIX via PSP (a definir)
